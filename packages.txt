# What neovimRC and weztermRC need on a machine. install.sh (macOS) and
# install.ps1 (Windows) read this file: anything missing gets installed.
#
# check  - command that must be on PATH; "-" = ask the package manager instead
# brew   - formula, or cask:<name>; "-" = not needed on macOS
# scoop  - app, or <bucket>/<app>; "-" = not needed on Windows
# the rest of the line says what needs it
#
# check    brew                  scoop                     what for
git        git                   git                       cloning configs and plugins, fugitive
gh         gh                    gh                        GitHub login: access to a private settings repo (KAZRC_REPO)
nvim       neovim                neovim                    the editor (0.12+)
wezterm    cask:wezterm@nightly  versions/wezterm-nightly  the terminal
rg         ripgrep               ripgrep                   Telescope live grep
fd         fd                    fd                        Telescope find files
node       node                  nodejs-lts                Mason: pyright, ts_ls, html, cssls, vimls
magick     imagemagick           imagemagick               image previews in Telescope
dotnet     cask:dotnet-sdk       dotnet-sdk                roslyn (C#) language server
tree-sitter tree-sitter-cli       tree-sitter               building treesitter parsers (highlighting, debugger values)
gcc        -                     gcc                       compiling treesitter parsers (Xcode tools cover it on macOS)
pwsh       -                     pwsh                      WezTerm shell, nvim shell, powershell_es
7z         -                     7zip                      Mason unpacking archives
